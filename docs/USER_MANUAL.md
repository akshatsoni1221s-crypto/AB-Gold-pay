# GoldPay ERP - User Manual

## Getting Started

### Accessing the System
1. Open your web browser and navigate to your GoldPay ERP URL
2. Enter your credentials (email/phone and password)
3. Click **Sign In**

### Dashboard Overview
After login, you'll see the Dashboard with:
- **Today's Sales**: Total sales for current day
- **Today's Profit**: Calculated profit (sales - cost)
- **Monthly Income**: Current month's total income
- **Stock Value**: Total value of all inventory
- **Pending Payments**: Outstanding customer/supplier payments
- **Recent Activities**: Latest system actions
- **Top Products**: Best-selling items
- **Low Stock Alerts**: Items needing restocking

## Inventory Management

### Adding a Product
1. Go to **Inventory** from sidebar
2. Click **Add Product**
3. Fill in:
   - Product name, barcode, SKU
   - Category, metal type, purity
   - Gross weight, net weight, stone weight
   - Making charges, wastage percentage
   - Purchase price, selling price, MRP
   - Stock quantity, minimum stock level
4. Click **Save**

### Searching Products
- Use the search bar to find by name, barcode, SKU
- Filter by category, metal type, purity
- Scan barcode using mobile camera (click camera icon)

### Stock Management
- View stock quantities in product list
- Low stock items highlighted in red
- Click product for full stock movement history

## Billing

### Creating a New Invoice
1. Go to **Billing** > **New Invoice**
2. Select customer (or create new)
3. Search and add products
4. Adjust quantities, prices, discounts
5. Select invoice type (GST/Normal/Quotation)
6. Choose payment method
7. Click **Generate Invoice**

### Understanding GST Invoice
- CGST: Central GST (9% for most items at 18% rate)
- SGST: State GST (9%)
- IGST: Integrated GST (18% for inter-state)
- HSN code: Product classification code

### Invoice Actions
- View: See full invoice details
- Print: Direct printing
- Download PDF: Save as PDF
- Email: Send to customer
- WhatsApp: Share via WhatsApp

## Customers

### Adding a Customer
1. Go to **Customers**
2. Click **Add Customer**
3. Enter name, phone (mandatory), address, GST number
4. Set credit limit if applicable
5. Click **Save**

### Customer Details
- View purchase history
- Check outstanding balance
- See payment history
- Access customer ledger

## Suppliers

### Managing Suppliers
1. Go to **Suppliers**
2. View all suppliers and their details
3. Track purchases and pending payments
4. Access supplier ledger

## Accounting

### Daily Cash Book
1. Go to **Accounting**
2. Select date to view cash book
3. See sales, expenses, collections, closing balance
4. Add expenses directly

### Recording Expenses
1. Click **Add Expense**
2. Select category (Rent, Salary, Electricity, etc.)
3. Enter amount and description
4. Click **Save**

## Reports

### Generating Reports
1. Go to **Reports**
2. Select date range
3. Choose report type:
   - Sales Report
   - GST Report
   - Inventory Report
   - Customer Report
   - Profit & Loss
   - Stock Valuation
4. Click **View**, **CSV**, or **PDF**

## Notifications
- Check bell icon for unread notifications
- Low stock alerts
- Payment reminders
- Backup reminders
- System alerts

## Settings

### Company Information
- Update company name, address, phone, email, GST
- Customize invoice settings
- Configure notification preferences

### Password Change
- Go to Settings > Security
- Click **Change Password**
- Enter current and new password

## Tips
- Use barcode scanner for faster product lookup
- Set minimum stock levels to get alerts
- Run reports regularly for business insights
- Create daily backup via Settings
- Use filters for faster data navigation
